Text Input

Textarea

複数行のテキスト入力です。お問い合わせ内容やコメントの入力に使用します。

Select

ドロップダウン選択です。配送先や支払い方法の選択などに使用します。

Checkbox

複数選択が可能なチェックボックスです。利用規約の同意やオプション選択に使用します。

Radio Button

単一選択のラジオボタンです。配送方法や支払い方法の選択に使用します。

Quantity Input

数量選択の専用コンポーネントです。商品詳細ページやカートで使用します。

Search Input

検索用の入力フィールドです。アイコン付きで検索機能であることを明示します。

Form Layout

複数のフィールドを組み合わせたフォームレイアウトの例です。
