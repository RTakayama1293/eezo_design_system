Buttons

EEZO Design System - ボタンコンポーネント

Primary Button

最も重要なアクションに使用します。1画面に1つが理想的です。 フォーム送信、購入手続きなど、ユーザーに最も取ってほしい行動に使用します。

<button class="btn btn-primary">カートに入れる</button>

Secondary Button

二次的なアクションに使用します。「もっと見る」「詳細を見る」など、 補助的な行動を促す場合に適しています。

<button class="btn btn-secondary">詳細を見る</button>

Gold Button (CTA)

特別なアクション、プレミアム感を強調したい場合に使用します。 「今すぐ購入」「特別セットを見る」など、ユーザーの興味を引きたい場面に最適です。

<button class="btn btn-gold">今すぐ購入</button>

Ghost Button

ダーク背景上で使用するボタンです。ヘッダーやヒーローセクションなど、 Navy背景上で使用します。

<button class="btn btn-ghost">商品を見る</button>

Text Button

最も控えめなボタンスタイルです。「戻る」「キャンセル」など、 強調を最小限にしたいアクションに使用します。

<button class="btn btn-text">戻る</button>

Button States

各ボタンには、デフォルト、ホバー、アクティブ、無効の4つの状態があります。

デフォルト
ホバー
アクティブ
無効

Full Width Button

モバイルのフォームやカートなど、幅いっぱいに表示したい場合に使用します。

<button class="btn btn-primary btn-full">購入手続きへ進む</button>

Button with Icons

アイコン付きボタンは、アクションの意味をより明確に伝えます。 アイコンは左右どちらにも配置できます。

Usage Guidelines

ボタンの優先順位

1画面にPrimaryボタンは1つが理想。複数のアクションがある場合は、 Primary + Secondary の組み合わせを使用してください。

ラベルは動詞で

「購入する」「カートに入れる」「詳細を見る」など、 具体的な動詞でアクションを明示してください。

十分なサイズ

タッチデバイスでの操作を考慮し、最小44x44pxの タップ領域を確保してください。

状態の明示

ホバー、フォーカス、無効状態を視覚的に区別し、 ユーザーにフィードバックを提供してください。
